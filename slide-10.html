Bundle What Repeats

If every run of a skill rewrites the same helper script, the script belongs in the skill.

scripts/
deterministic, repetitive operations. Write it once; let the skill call it.
references/
documentation the skill loads only when relevant. Add a table of contents to long files.
assets/
templates, fonts, and files used in the final output.
Two rules that protect you
Use relative paths (./scripts/helper.py), never absolute or ~ paths.
Never embed API keys, tokens, or credentials. A published skill can execute code, so a leaked secret is a real attack surface.
