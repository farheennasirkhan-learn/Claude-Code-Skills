Common Skill-Building Mistakes

Step through each pairing — the mistake and the move that fixes it.

Common mistake
Better move
Vague description
Say what it does and when to use it.
Wall of ALL-CAPS rules
Explain the reasoning; let the model generalise.
Dumping everything into SKILL.md
Push detail into reference files; keep the body lean.
Building a skill for a one-off
Save skills for workflows that actually repeat.
Hard-coding one example
Write for the general case, test on several.
Embedding secrets or absolute paths
Use environment variables and relative paths.
A good skill is small, clear, and trusted enough that the whole team reaches for it.
