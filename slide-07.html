Building Claude Code Skills · 06

Progressive Disclosure

Load Only What You Need

Skills are efficient because Claude does not read everything at once. It loads in three levels.

1
Metadata
Name and description (~100 words)
Always in context
2
Body
The full SKILL.md instructions
When the skill triggers
3
Resources
Scripts, references, assets
Only as the task needs them
This is why the description must do its job at level one, and why a bloated SKILL.md is a cost. Keep the body under roughly 500 lines; push detail into reference files the skill points to.
