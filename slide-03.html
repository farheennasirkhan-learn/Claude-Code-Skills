What a Skill Actually Is

A skill is not code. It is teaching.

At its simplest, a skill is one folder with one file:

my-skill/
SKILL.md Required
scripts/ Optional
references/ Optional
assets/ Optional
Optional

Optional bundled resources: scripts, reference docs, and assets.

---
name: status-report-builder
description: when and what the skill does
---

The frontmatter needs only two fields: a name and a description. Everything else is instructions written in plain language.

Claude reads a skill only when the task calls for it. The rest of the time it stays out of the way.
Most useful skills contain no code at all, just clear, well-organised instructions.
